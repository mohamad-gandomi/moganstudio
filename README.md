# Mogan Studio

Mogan Studio is a single Next.js marketing site for WordPress, WooCommerce, and custom web development.

## Local setup

```bash
npm install
npm run dev
```

The site uses static project and service data. Contact is handled through WhatsApp, Calendly, and email, so no application server, database, or secret environment variables are required.

## Production

Deploy the repository root as a Next.js project on Vercel. Enable Vercel Analytics if desired.
